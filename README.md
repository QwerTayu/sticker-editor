# sticker-editor

背景が透明な画像を並べてステッカーをデザインし、入稿用の PNG を書き出すエディタ。台紙（白いふち）とカット線をその場で計算して表示する。

`editor.html` をブラウザで開くだけで動く。ビルドもサーバーも要らない。

## 使い方

1. `editor.html` をブラウザ（Chrome・Edge・Safari・Firefox の最近の版）で開く。
2. 「画像を追加」を押すか、画像をキャンバスにドロップする。PNG・JPEG・WebP・GIF に対応していて、複数まとめて追加できる。背景が透明な PNG を使うと、輪郭に沿った台紙になる。
3. 画像を並べる。
   - ドラッグで移動する。矢印キーで 1px、Shift を押しながらだと 10px 動く。
   - ホイールで拡大縮小、Shift＋ホイールで回転する。
   - 右のパネルで、重ね順・倍率・回転・位置を数値で変えられる。Delete キーで削除する。
4. 台紙の形を選ぶ（輪郭・円・長方形・正方形）。円・長方形・正方形は、中身に合わせて自動で大きさが決まる。手動で中心と大きさを指定することもできる。
5. 横幅（cm）を決めて「PNG を保存」を押す。300 dpi の PNG が書き出され、dpi の情報も PNG に入る。

作業の途中経過（画像と配置）はブラウザに自動で保存されるので、同じブラウザで開き直せば続きから作業できる。

### 画像ごとの設定

| 設定 | 内容 |
|---|---|
| 倍率を連動する | チェックを付けた画像どうしは、どれかの倍率を変えると全部同じ倍率になる |
| ノイズ除去 | 透過部分に残った細かい点を取り除く。細い線（ケーブルなど）が消えるときは外す |
| 重なり判定：全体 | 画像の不透明な部分すべてを、他の画像と重なってはいけない範囲として扱う |
| 重なり判定：本体のみ | 一番大きい塊と、それより上にある飾りだけを重なり判定に使う。下にある風の線などは隠れてもよい扱いになる |

本体どうしが重なると、パネルとキャンバス上に赤で表示される。

### 保存と共有

| ボタン | 中身 | 用途 |
|---|---|---|
| 配置をコピー | 配置・台紙の設定の JSON（画像は入らない） | Claude などに配置を伝える。下の欄に貼って「テキストの配置を読み込む」で戻せる |
| プロジェクトを保存 | 配置の JSON に画像を埋め込んだもの（`sticker-project.json`） | 別のブラウザや人に作業を渡す。「プロジェクトを開く」かドロップで開ける |
| PNG を保存 | 入稿用の PNG（`sticker.png`） | 印刷所に入稿する |

ブラウザに保存した内容は、そのブラウザの中にしか残らない。残しておきたい作業はプロジェクトファイルに保存しておく。

## Python で書き出す（任意）

エディタの「PNG を保存」とは別に、`render_layout.py` でも同じ配置から PNG を書き出せる。台紙の計算を scipy で行う。カット線入りの確認用画像（`*-preview.png`）も一緒に作り、本体どうしの重なりや、中身が台紙からはみ出していないかを表示する。

Pillow・numpy・scipy が必要。

```sh
pip install pillow numpy scipy

# プロジェクトファイルから（画像が埋め込まれているので、これだけで書き出せる）
python render_layout.py sticker-project.json            # → sticker-project.png
python render_layout.py sticker-project.json out.png

# 配置だけの JSON から（画像は --images のフォルダの <name>.png などを使う。省略時は JSON と同じフォルダ）
python render_layout.py layout.json out.png --images ./images
```

|---|---|
| `editor.html` | エディタ本体（HTML 1 枚で完結） |
